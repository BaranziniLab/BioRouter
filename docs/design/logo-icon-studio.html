The BR mark sits low — because the underline was never counted

The letters are centered, then the underline is added below them, so the real mass drops. This tool centers the union of the letters and the underline as one body, and gives you two dials — vertical position and mark size — with the centered, slightly-smaller setting as the default. Tune it, then export your setup as text and send it back.

Dials

50%

The share of the icon the letters + underline fill, top to bottom. Font-independent, so the number means the same thing when it reaches the real asset. The default is smaller than the current, oversized mark.

0 px

0 = the letters + underline are centered as one body. Negative nudges up, positive down. Size changes never un-center it — the offset is measured from true center.

8%

Space between the letters and the underline, as a share of cap height — so it scales with the mark. The default keeps the underline close to the text. Counts toward the centered body, so changing it re-centers automatically.
