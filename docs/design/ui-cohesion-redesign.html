What changed & why

Seven cohesion fixes. Every value is drawn from the existing Parchment tokens — nothing new is invented, it's re-organised so the panels align. Refs point at the signed-off system doc.

A

A brand band that anchors the top

The wordmark floated 40px down with no connective tissue to the menu. It now sits in a 52px band with a bottom hairline — the same height as the chat and preview headers, so all three panel tops align across one line.

Nowbare text, 40px top gap, no mark
Newlogo lockup + wordmark, 52px band, hairline
design.md §4.11 · §3.3 page-shell
B

The menu is a labelled zone

The nine destinations now sit under a quiet MENU caption, so the built-in app functions read as a group distinct from your conversations below.

Nowunlabelled stack, blends into history
New"Menu" section label, 11px caps
design.md §4.11 section-label
C

Menu and history are visibly separate

A 32px-wide hairline was the only divider between built-ins and chat history. It becomes a full-width rule, and the Recents list gets its own inset scroll-well — a clear boundary between "what the app does" and "what I've done".

Nowtiny 32px hairline, flush list
Newfull-width rule + inset Recents well
design.md P2 rows-not-cards
D

History rows carry a glyph

Chat rows were a wall of identical text. A subtle leading glyph now distinguishes them from menu items — a speech mark for chats, a branch mark for diverged sessions, an app tile for apps. Live sessions keep the pulsing coral dot.

Nowtitle only, no glyph (§4.11 as-built)
New14px conversation / branch / app glyph
your ask · revisits §4.11 "no leading icon"
E

One type rhythm, sidebar ↔ chat

Both already use the system stack, so the mismatch was rhythm, not family: the wordmark was leading-none while rows breathed. Everything now shares one scale — 14/20 rows, 11px caps labels, 12px date labels — so the rail and the transcript feel set by the same hand.

Nowmixed leading & weights
Newshared 14/20 + 11px caps scale
design.md §3.2 type scale · D-06
F

Three headers, one bar

Sidebar band, chat header and preview header are now all 52px on the same ground with the same single hairline — a continuous top edge across the whole window instead of three headers at slightly different weights.

Nowheaders match; sidebar top doesn't
Newall three top edges aligned
design.md §4.12 · P1 hairline
G

The preview panel joins the system

Preview tabs were 8px-radius with a drop shadow and a scatter of one-off label sizes (10.5 / 9.5 / 11px). They now match chat: 12px radii, flat tabs, and a single 11px caps label token — so the preview looks like part of the app, not a separate widget.

Now8px tabs + shadow, 10.5/9.5px labels
New12px radii, flat, one 11px caps label
