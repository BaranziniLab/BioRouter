BioRouter · Theme proposal · Draft for approval

Alma Mater

A second theme that dresses BioRouter in the official UCSF brand palette — navy-anchored, cool-neutral, with a UCSF Violet / eggplant accent as the elegant twist. It is a re-colouring only: same layout, same flat-surface discipline, same fonts, genuine light and dark. The current look is renamed Parchment and stays the default.

Font: unchanged Modes: real light + dark Accent: UCSF Violet (G-column) Contrast: WCAG AA verified Layout change: none
