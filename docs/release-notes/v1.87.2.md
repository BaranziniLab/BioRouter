# Biorouter v1.87.2 Release Notes

**Release Date:** July 2026
**Repository:** [github.com/BaranziniLab/biorouter](https://github.com/BaranziniLab/biorouter)

This release reworks the chat surface around three new capabilities: a **side
artifact viewer** that auto-detects figures and HTML the agent produces, an
**in-app tabbed terminal** rooted in the session directory, and a **Local Model
Inventory** that installs, warms up, and deletes local models without leaving
Settings. The composer was streamlined at the same time — slash-command
discovery is back, the context meter is now a compact ring, and the controls no
longer collapse in a narrow window. No breaking changes — existing installs
upgrade in place, and your settings, sessions, extensions, and knowledge bases
are preserved.

The two **CLI-only** packages install just the headless binaries (`biorouter` +
`biorouterd`) with no Electron/GUI payload — ideal for servers, HPC nodes, and
containers. (Local models need glibc ≥ 2.35 — Debian 12+/Ubuntu 22.04+.)

macOS builds are signed and notarized with the UCSF Developer ID certificate.
Users on v1.86.0 or later can update in place with the one-click **"Restart &
Update"** button — no need to re-download the DMG.

## What's New

### Local Model Inventory

Model settings gain a Local Model Inventory section that lists the curated Llama
Server and Ollama models with install, warm-up, delete, refresh, and detail-view
actions in one place. Each entry now shows its model family, context window,
memory suitability, on-disk cache path, and a link to the official model page,
with per-action progress and error feedback instead of a silent spinner.

The curated catalog was expanded with additional Gemma 4 and Qwen3.6 variants
and now carries family metadata and official Ollama library URLs. A new
`/llamacpp/delete` route stops the active sidecar when necessary and removes
cached Hugging Face model directories, so reclaiming disk space no longer means
hunting through the data directory by hand. The switch-model modal shows concise
labels with searchable detail metadata, making the Gemma and Qwen options
easier to compare.

### Side artifact viewer

Figures and HTML the agent generates are now detected automatically — from both
assistant text and tool responses — and open in a resizable side panel next to
the conversation. Artifact titles are derived from the Auto Visualiser `ui://`
resource URI, so charts arrive labeled by what they are rather than by an opaque
identifier; `show_chart` now emits chart-kind URIs so line, scatter, and bar
charts surface as distinct artifacts.

Opening an artifact in a narrow window asks the Electron window to widen first,
bounded by the active display's work area, so the panel no longer appears and
immediately tucks away. When a figure fails to render, the Auto Visualiser frame
reports a structured render error back to the viewer, which feeds the failure
into the session as repair context.

### In-app terminal

A terminal action in the chat header opens a tabbed terminal dock rooted in the
current session's working directory. Tabs can be opened and closed individually;
closing the last one hides the dock.

### Session review popover

A review action in the chat header reports the session's tool calls, token
usage, artifact count, and code delta. Workflow and diagnostics actions moved
out of the composer and into this popover.

### Streamlined composer

Slash-command discovery is back in the composer, listed alongside knowledge
bases, skills, and extensions, with keyboard navigation and Tab insertion from
the popover. The chat-box CLI launcher, paperclip attach button, and
workflow/diagnostics buttons were removed — drag-and-drop attachment still
works.

The linear context display is now a compact circular ring with a detailed
hover/popover gauge, the cost tracker renders with a plain keyboard dollar sign,
and the status controls are ordered model → context → cost, ending just before
Send. Send and stop share one square icon-button geometry, with only the center
glyph changing.

### Conversation title menus

Renaming a conversation moved behind a three-dot title actions menu — the title
text itself is now read-only, so a stray click no longer drops you into an edit
field. The same menu exposes **Diverge**, which branches the conversation from
the latest assistant response. Both are available on the main chat pill and on
dashboard window title bars.

### Refreshed model pricing

Canonical model pricing and naming coverage were refreshed, with pricing data
extended across the provider catalog so the in-chat cost tracker stays accurate
for recently added models.

## What's Fixed

### Deterministic slash calls and file attachments

Slash-command invocation and file attachment handling were rebuilt to behave
deterministically, with drag-and-drop drop-target coverage in `useFileDrop`.

### Terminal layout and input

Terminal panes stayed measurable while switching tabs, so xterm no longer
collapses to a zero-size hidden surface. Reopening the dock selects an existing
pane, focus lands on the terminal consistently, and plain keystrokes typed on
the dock chrome are forwarded to the active backend session. Closing the last
tab no longer triggers a React render-phase update warning — the dock close is
deferred to an effect.

### Artifact preview interaction

The artifact viewer header and its action buttons now sit on an explicit
stacking layer above the embedded iframe, so open-outside and close reliably
receive pointer events under Electron. The viewer and its header controls are
marked no-drag so window chrome hit-testing can't swallow the clicks. Resizing
keeps the artifact mounted rather than tucking it away.

### Composer controls at narrow widths

The compact chevron toolbar mode was removed, so model, context, and cost
controls stay inline at every width. Dashboard conversation windows open at a
760px minimum width to give the composer room.

### Ollama model management

The Ollama pull request body now uses Ollama's `model` field, and deleting an
Ollama model is supported. Llama Server correctly falls back for Ollama-sourced
models, and the warm-up dialog reports accurate labels.

### Workflow form subscriptions

Workflow form field subscriptions are now cleaned up on unmount.

## Upgrade Notes

No configuration changes are required. `~/.config/biorouter` (your providers,
sessions, extensions, and knowledge bases) is untouched by the upgrade.

The in-app terminal ships native `node-pty` and `xterm` modules, unpacked from
the app archive at install time; the renderer falls back gracefully if the
native module is unavailable on your platform.
