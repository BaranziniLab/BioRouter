A quiet instrument.

BioRouter is a warm, low-chroma, flat-surface research console — paper-like rather than glassy, dense rather than airy, and confident enough to stay silent. Colour is evidence, not decoration.

This page renders every token and every UI element in both themes at once, so the specimen is the spec. Where a genuine aesthetic trade-off exists, you'll find a decision block. All 14 were signed off on 2026-07-09 and the fix pass has shipped; two further decisions (D-15 focus, D-16 the user's turn) were added after seeing the accent land in the running app.

01 — Identity

The vibe, stated plainly

A tool that clinicians and computational biologists keep open for eight hours. It sits next to a terminal, a genome browser, and a stack of PDFs. It must never look like it is trying to sell them something.

Five adjectives, in priority order

AdjectiveWhat it forces
CalmNothing pulses, glows, or gradients without a reason grounded in state.
PreciseHairlines, tabular numerals, consistent optical alignment. The UI should feel machined.
WarmThe neutral ramp is biased toward paper and bone — never blue-grey steel.
DenseInformation-per-pixel is a virtue. Rows beat cards. Text beats iconography.
TrustworthyStatus is legible at a glance. Destructive actions look destructive.

Lineage — what it borrows from

Sits between
The scientific instrument panel
Tektronix · LabVIEW · IGV — dense readouts, monospace as a first-class citizen, colour reserved for signal.
The editorial reading surface
Readability · iA Writer — warm paper ground, generous measure in prose, restrained typography.
The modern developer console
Linear · Zed · Codex — flat surfaces separated by hairlines, keyboard-first, near-zero chrome.
Never
  • Glassmorphism. No frosted panels over blurred wallpaper. The one legitimate blur is the modal scrim.
  • Multi-layer shadows faking depth on ordinary content.
  • Gradient heroes or a saturated brand colour as a background fill.
  • Colour as decoration. A coloured divider that doesn't encode state is a bug.
  • Cold neutrals. Tailwind's blue-greys are foreign bodies here.
  • Emoji as UI. Icons are line-drawn and monochrome.
  • Bouncy motion. No spring overshoot. Motion is short and informative.
02 — Principles

Eight rules that force decisions

A principle that forces nothing is a platitude. Each of these is stated with the concrete rule it produces.

#PrincipleForces
P1Surfaces, not elevationDepth = a 1px hairline + a change of ground. Shadow is permitted on exactly four things: the modal, the popover, the toast, the composer. Nothing else.
P2Rows, not cardsIf you can scroll past three of them, they are rows. Cards are for standalone objects only.
P3Colour is evidenceCoral means "primary action" or "live". Status hues mean status. Hover is a neutral tint. No coloured dividers, no rainbow tags.
P4One control, one look<Button> not <button>. A className override that changes colour, radius, height or border is a missing variant.
P5Everything reachable shows itOne focus treatment app-wide: 2px ring, 2px offset, ≥3:1 on every ground it can appear on.
P6The monospace layer is designTerminals, code, diffs and logs are tokens — derived from the ramp, and authored for both themes.
P7Both themes ship, or neitherNo hardcoded white inset highlights. A token with no .dark value is an incomplete token.
P8Density is a budget4 radii · 6 spacing steps · 7 type sizes · 3 durations. A new value requires deleting an old one.

Today, the code violates six of the eight. Cards ship a shadow by default (P1). The toast is hardcoded dark (P7). Code renders in Arial (P6). The focus ring is 1.14:1 (P5). 103 raw <button> elements bypass the component (P4). Seven radii are in use (P8). Each is catalogued in the drift register.

03.5 — Foundations

Focus & motion

DR-15 fixed DR-16 fixed — 0 competing treatments D-15 focus = surface shift

Focus is a surface shift, never a ring. The focused control deepens its own fill by one step and firms its existing edge. Nothing is drawn around it.

Why the ring is gone. A 2px coral outline around every focused control read as an alarm on a surface whose whole thesis is calm. Worse, browsers treat text fields as permanently :focus-visible, so the outline fired on an ordinary mouse click — wrapping the chat composer in a bright orange rectangle. The indicator was correct by the letter of WCAG and wrong for this product.

Before this pass the ring was also invisible: #f4f0e6 on white is 1.14:1. 68 outline-none classes and 54 focus:ring-* utilities have been removed; the treatment is now global and there are zero per-component overrides.

    outline: 2px solid var(--ring);
    outline-offset: 2px;
  }
}

This is a product decision, not an oversight. Revisit it under a strict Section 508 / EN 301 549 review.

08 — Sign-off

Open decisions

✅ Signed off 2026-07-09 — and implemented. Recommendations were accepted for D-01…D-11, D-13 and D-14. D-12 was overridden to option B (40px rows everywhere, no compact mode). D-08 shipped in two stages: the visual + layering fix is done; the react-select → Radix + cmdk swap is scoped separately because the model picker is a typeahead combobox.

Two decisions were added afterwards, once the accent was visible in the running app:

  • D-15 · Focus indication — a surface shift, not a ring. No outline anywhere. The coral outline read as an alarm, and fired on mouse clicks because browsers treat text fields as permanently :focus-visible. Supersedes the D-03 answer. See Focus.
  • D-16 · The user's turn — tinted, not accent. It shipped as bg-background-accent, so the moment D-01 made the accent coral, every user message became a solid orange block.
  • D-17 · Tool calls — lines, not cards. No outline, collapsed or expanded. A persistent 1px rectangle around every tool call reads as a stuck focus ring. Failure is signalled by colour and a 5% danger wash.
  • D-18 · Hairlines — one value. Eight alpha-diluted variants (/35…/70) made adjacent panels' edges read at different weights, so the chat banner and the artifact-panel header never visually aligned.

The blocks below are retained as the rationale record, ordered by blast radius.
