# Biorouter v1.88.6 release notes

**Release date:** July 27, 2026

**Repository:** [github.com/BaranziniLab/biorouter](https://github.com/BaranziniLab/biorouter)

Biorouter v1.88.6 is a reliability and fit-and-finish release. It closes **every open
issue on the tracker** — twenty-four reports spanning headless concurrency, the agent's
tool surface, provider coverage, local models, and the desktop interface. The headline
fixes are the ones that made parallel work unsafe: concurrent headless runs could abort
with a database error, and unattended runs could stall for half an hour on a permission
prompt nobody could answer. Both are gone, verified under a deliberate stress test.

Existing settings, sessions, providers, extensions, skills, workflows, applications,
knowledge bases, and usage history remain compatible.

## Parallel and headless work is now safe

**Concurrent runs no longer collide on the session store.** Running several
`biorouter run` jobs at once — or one job while the desktop app was open — could abort
with `UNIQUE constraint failed: messages.session_id, msg_uid`, emitting empty output.
The cause was not the session-id allocator that the reports suspected: the **Bedrock
streaming decoder** stamped one shared message id across every message it yielded and
never batched tool-use blocks, so a single response could persist two assistant messages
sharing an id. The decoder now batches like the Anthropic path, the agent re-mints
duplicate ids within a turn, and the store treats an exact replay as an idempotent
success. Verified with 52 concurrent tool-heavy sessions across two providers with the
desktop app open on the same database: zero collisions.

**`--no-session` is genuinely isolated.** It now builds a private per-run store in a
temporary directory instead of writing the shared `sessions.db`, and cleans up after
itself (closing the SQLite pool before removing the directory).

**Unattended runs fail fast instead of hanging.** A tool call needing approval in a
non-interactive run used to render an interactive prompt on stdout — corrupting
`--output-format json` — then block for ~30 minutes and die with `Error: not connected`.
Non-interactive runs now auto-deny immediately with a clear message on stderr, hand the
denial to the model as a tool result so the turn completes, and always emit exactly one
valid JSON document. Elicitation requests can now preempt a parked tool call and are
scoped per session, and session-store failures carry their own exit code instead of
masquerading as provider errors.

## Agent tool surface

- **Shell tools find your tools again.** The `developer` shell ran with a truncated
  `PATH`, so Homebrew-installed binaries (`gh`, `brew`, and friends) were "not found" on
  a standard Apple Silicon setup. The shell now appends the standard user-tool
  directories, covering foreground and background jobs.
- **Self-correcting sandbox errors.** Generated JavaScript embedding shell or CSS in a
  template literal failed to parse with no path forward. The error now explains the
  actual cause (`String.raw` does *not* make `${…}` literal) and offers concrete
  recoveries; the tool descriptions no longer recommend the trap.
- **Web fetching is more robust.** `web_scrape` uses a browser-compatible user agent
  (the old one drew bot-blocking 403s), a 30-second timeout, and one retry on transient
  failures — never on 403/404 — with status-preserving errors.
- **Empty searches are results, not failures.** `search_modules` with no matches returns
  guidance instead of a hard tool failure, and knowledge-base write rejections now say
  what to do instead.
- **Operator-disabled extensions stay disabled.** The agent can no longer silently
  re-enable an extension you turned off in config; it is told to ask you.

## Providers and models

- **Claude Opus 5** is a first-class Anthropic model, with the correct 1M context window
  and pricing.
- **Claude Opus 4.8 on UCSF Versa Bedrock** — verified end-to-end through the proxy.
- **Moonshot (Kimi)** joins as a direct provider (`MOONSHOT_API_KEY`) with the K2 family,
  real context windows and prices, and reasoning-content passthrough scoped to the
  capturing provider.
- Deep-effort turns no longer send parameters the modern Claude models reject.

## Local models

- **The high-memory default is now fast.** Machines with 64 GiB or more preselected a
  35B mixture-of-experts model with a 24 GB download; the default is now a fast dense
  mid-size model, with the large model available as an explicit choice.
- **Every model shows its expected speed** next to its download size, in onboarding and
  in the model inventory.
- **Download progress survives navigation.** Progress lived in component state and froze
  when you clicked elsewhere, making a running download look dead. A shared store now
  owns the poll loop, so progress stays live wherever you go.

## Desktop

- **Typing stays responsive while a reply streams.** Each streamed token used to trigger
  three synchronous re-renders of the whole chat view; updates now batch to one flush per
  frame, with the composer isolated from transcript churn.
- **Closing the last tab returns Home** — to the usage heatmap — instead of a dead-end
  empty pane. Sessions are never deleted by closing a tab.
- **Cmd+W closes what you mean.** With a terminal focused it closes that pane, then the
  chat tab, then the window — instead of tearing down the window immediately.
- **The active tab carries an accent strip** and tabs slide with a spring easing when
  reordered or closed.
- **Tool calls show what actually happened.** Condensed rows name the exact module,
  search terms, or skill; a coordinated multi-tool step lists each executed call with its
  arguments, status, and real error text, attributed to the specific tool that failed.
- **Friendlier artifact errors.** A moved or deleted file shows "This file was moved,
  renamed, or deleted" instead of a raw `ENOENT` string.
- **Your chosen working directory sticks.** Picking a directory before the first message
  no longer reverted to the default.

## Working directory is now fixed once a chat starts

Changing a session's working directory mid-conversation broke every file reference the
agent had already produced. The directory is now chosen while the chat is empty and
locked afterwards: the composer chip becomes a read-only label showing the folder name,
with the full path on hover, and the server refuses late changes. The assistant is also
instructed to print absolute paths for files it creates, so previews always resolve.

## Headless server

`biorouter-headless serve --public-url` accepts the URL prefixes it should — including
`@` and percent-encoded characters, which JupyterHub-style proxies need — while still
rejecting anything that could break the pages it serves.

## Command line

`biorouter skill enable` and `biorouter skill disable` join `install`/`list`/`remove`, so
headless and CLI users get the per-skill control the desktop app already had. `skill
list` shows each skill's source, name, and enabled state.

## Upgrading

macOS users on 1.88.x can take the in-app update. Everyone else: download the artifact
for your platform above. No migration steps are required.
