# Biorouter v1.89.7 release notes

**Release date:** August 26, 2026

**Repository:** [github.com/BaranziniLab/biorouter](https://github.com/BaranziniLab/biorouter)

v1.89.7 is a reliability patch for delegated agents, knowledge curation, and the file preview
panel. A running child is now visibly running, remains steerable after its tab closes, and can be
reattached without losing its event stream. The preview panel now binds everything it gives an
agent to the exact document, website, revision, chat split, and selected rectangle the user saw.

This release also completes the knowledge-format migration. Biorouter now supports current OKF
and BioOKF bases only, and the built-in `soul` base is recreated as native OKF. A base is removed
at startup only when it positively identifies itself as pre-OKF; anything Biorouter cannot diagnose
with certainty is left exactly where it is, reported, and skipped, so a damaged manifest can neither
destroy a current base nor stop the app from starting. Export legacy content with an earlier
Biorouter release before updating if it must be retained.

## Delegated agents stay visible, steerable, and alive

- A selected running child tab keeps the existing breathing activity dot visible, including on
  hover, and its composer uses the same existing moving rim as an ordinary running conversation.
  No new animation was introduced.
- Closing a child tab detaches only that view. It does not pause or cancel the child; reopening the
  same session reattaches to the authoritative replay stream.
- Prompts can steer a running child, and direct follow-ups restore parent supervision after older
  results have been collected.
- Detached turns claim their stream before starting, publish turn-attributed terminal events, and
  survive observer reconnects without an idle flash or a stale Running state.
- Codex and Claude Code retain their exact delegated capability profile. Codex, Claude Code,
  Versa Azure OpenAI, and Versa Bedrock bindings persist and restore without collapsing a
  provider-specific route into a generic one.
- Coding-agent turns have no hidden wall-clock deadline by default. An operator-configured ceiling
  covers the handshake as well as inference, and bridged tool waits are safely bounded without
  integer wraparound.

## OKF, BioOKF, and native Soul

- The empty Knowledge screen can create its first base, even when no previous registry or legacy
  database exists.
- Create, import, and delete operations publish atomically and roll back both files and metadata on
  failure. Interrupted staged operations are recovered at startup.
- `.brkb` import rejects path traversal, decompression bombs, mismatched identities, incomplete
  bundles, and legacy formats before publication.
- OKF and BioOKF ingest, lint, query, history, and restore paths use their current schemas. Native
  Markdown page links are returned as citations while external and traversal targets are refused.
- Registered and unregistered legacy knowledge residue is retired, but only on a positive
  identification made under the same locks that authorize the deletion, so a base replaced while
  the scan is waiting is no longer at risk. A base that cannot be diagnosed is kept and reported
  rather than removed. The built-in base is named exactly `soul` and is recreated in OKF format.
- A knowledge base whose structure is damaged now lints as an error instead of reporting a clean
  bill of health, and `biorouter knowledge list` reports what it finds without altering the store.

## Preview files and live websites safely

- Images, PDFs, Word documents, PowerPoint decks, and Excel workbooks render in the sidebar panel.
  Long PDFs release offscreen canvas memory, and hostile image or Office dimensions are rejected
  before expensive rendering.
- Websites run as a live, isolated browser surface with current URL, title, text, screenshot, and
  revision context. Page-created windows and sign-in redirects cannot trap the app in native
  dialogs.
- Panel reads and captures are scoped to the correct split chat and exact rendered file or website
  revision. A changed file or navigated page makes an older capture request stale instead of
  silently relabeling different content.
- Region annotations are clamped to the preview bounds. Temporary captures are removed when a
  queued annotation is discarded, while original user files are never deleted.
- The agent receives bounded text for searchable content and bounded pixels for visual questions;
  the user can annotate a region and ask for a targeted text or image change.

## Security and release checks

- Project-specific `.biorouterignore` rules now protect artifact reads outside the daemon's current
  directory.
- Live website metadata is bounded before it crosses the workspace bridge, embedded requests use a
  public-target proxy policy, and renderer-triggered external navigation follows one confirmation
  policy.
- The OpenAPI release gate regenerates the schema before comparing it, so committed server/client
  drift can no longer pass on a clean checkout.
