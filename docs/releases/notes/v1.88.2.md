# Biorouter v1.88.2 release notes

**Release date:** July 15, 2026

**Repository:** [github.com/BaranziniLab/biorouter](https://github.com/BaranziniLab/biorouter)

Biorouter v1.88.2 introduces the new router identity across every shipped
surface, standardizes the product name as **Biorouter**, adds recent-session
sidebar navigation, corrects current-week usage reporting, and expands artifact
previewing for documents, spreadsheets, notebooks, directories, and git-backed
workspaces.

Existing settings, sessions, providers, extensions, skills, workflows,
applications, knowledge bases, and usage history remain compatible.

## New Biorouter identity

- The supplied router mark is now the canonical vector used by renderer logos,
  application icons, Dock and taskbar icons, menu-bar glyphs, the CLI, the
  landing site, and design references.
- PNG, ICNS, ICO, updater, DMG, ZIP, DEB, and RPM surfaces are regenerated from
  the same SVG source.
- User-facing product copy and native package names consistently use
  **Biorouter** while internal package identifiers and the `biorouter` command
  remain stable for compatibility.

## Recent sessions and usage accuracy

- A recent-session list now lives directly in the desktop sidebar for faster
  navigation without leaving the active workspace.
- Title-bar controls remain interactive across compact, overlaid, and expanded
  sidebar states.
- The activity heatmap stops at the reporting window end, so future dates in the
  current week are no longer shown as zero-activity days.

## Rich artifact navigation

- The artifact viewer can preview Office documents, spreadsheets, notebooks,
  source files, and supported local assets from a single side panel.
- Directory and git-aware navigation make it possible to move through related
  files without repeatedly returning to chat.
- Renderer-to-main navigation is guarded by the existing local file permission
  policy and covered by focused regression tests.

## Release verification

The 1.88.2 release pipeline verifies Rust formatting, strict linting, workspace
tests, generated API consistency, desktop type-checking and tests, signed and
notarized macOS arm64/x64 apps, Windows desktop and bundled CLI startup, Linux
DEB/RPM desktop startup, CLI-only Linux packages, and the headless browser/server
archive.
