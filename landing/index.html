Why Biorouter

Composable AI agents for biomedical research

Build an agent from extensions, skills, knowledge, and the model you trust, then reuse it, schedule it, and share it. Made for sensitive data, reproducible results, and work that crosses institutions.

Composable workflows

Bundle extensions, skills, knowledge, and a model into one reusable unit. Share it across labs to run the same task on each site's own data. The workflow carries the instructions, not the records.

Knowledge that compounds

Biorouter helps you organize what you learn into a connected knowledge base. The agent reads from it in every chat, so it gets more useful the more you add.

Skills, the atomic unit

A skill is a set of instructions that teaches the agent to do one thing the same way every time. Use them to repeat a method exactly, control what the agent reads, or walk through a procedure step by step.

Connect to any database

Extensions connect the agent to outside systems over the Model Context Protocol: clinical data warehouses, biomedical knowledge graphs, literature APIs, and your own tools. Once added, they work in every session.

Every model, your trust boundary

Run institutional models on UCSF-hosted Azure OpenAI and Bedrock, local models with a built-in llama.cpp server (no setup) or Ollama, or commercial models like Claude, GPT, and Gemini. Pick what each task needs and switch from the same screen.

Scale and automate

Run many agents at once in Dashboard mode for coding, research, and analysis. Schedule workflows to run on their own, even when the app is closed.

A guided tour

Built for how researchers actually work

From a single question to many agents at once, the whole workflow stays in one window.

Home

One place to start every investigation

The Home screen opens with a prompt and an immediate cached summary of your work: session and token activity, your current streak, and the chats you opened most recently. Biorouter refreshes those insights quietly in the background, so you can continue an analysis or begin a new one without waiting on history to load.

Session analytics Token usage Recent activity
Chat

A conversation that reaches into your data

Ask a question in plain language and the agent gets to work. In this session it writes and runs OMOP SQL against a UCSF clinical warehouse, reads from your knowledge base, and calls skills, showing each step as it goes. You can change models partway through, or save a useful chat as a workflow in one click.

Live tool calls Knowledge & skill calling Model switching One-click workflow
Dashboard mode

Run many agents at once

Dashboard mode lays out many sessions on one canvas so you can run them side by side. Split coding, literature review, and data analysis across dozens of agents working at the same time, and organize, fold, and watch them from a single view.

Parallel sessions High throughput Coding & research Biomedical tasks
History

Nothing gets lost

Every session is saved, timestamped, and searchable, with message counts, token usage, and linked files grouped by day. Reopen last week's GWAS analysis, check how a result was produced, or import a colleague's session and run it yourself.

The agentic stack

Composable building blocks

Every agent in Biorouter is built from the same parts: extensions, skills, knowledge, and models. Configure them once, then reuse and share.

Workflows

Package an entire agent, not just a prompt

A workflow holds everything an agent needs in one file, so the same setup runs the same way each time. Share it across labs and institutions to keep results consistent, and to run the same task on each site's data without moving the data itself.

Extensions

Connect to any database or service

Extensions give the agent access to outside systems. Over the Model Context Protocol, add clinical data warehouses, biomedical knowledge graphs, literature APIs, memory, and your own tools. Each extension adds abilities the agent can use in any chat.

MCP connections Databases Services & APIs Custom tools
Skills

The smallest piece you build an agent from

A skill is a set of instructions that teaches the agent how to do something and do it the same way every time. Skills are good for repeating a method exactly, controlling what the agent reads, and explaining or reproducing a process. Each one is small and shareable, and you can combine several for bigger jobs.

Replication Context engineering Explain & reproduce Composable
Knowledge

A personal knowledge base that gets more useful as you go

Biorouter helps you build a personal knowledge base, organizing what you learn into a connected graph. The agent reads from it in every conversation, and it gets more useful as you add to it. Drop in documents and the agent can use them right away.

Scheduler

Put your research on autopilot

Set workflows to run on a schedule you choose: a nightly literature check, a weekly data pull, a regular analysis. Set up the task once and it runs on its own, with the results ready when you come back.

Automation Cron schedules Recurring tasks
Models & providers

Every model, your choice of trust boundary

Biorouter works with every major provider, grouped into three kinds. Institutional models run on UCSF-hosted Azure OpenAI and Bedrock for sensitive data. Local models run on a bundled llama.cpp server — no Ollama, no setup — or through Ollama, and never leave your machine. Commercial models include Claude, GPT, Gemini, and many more. Pick what a task needs, switch whenever you want, and your API keys stay encrypted on your device.
